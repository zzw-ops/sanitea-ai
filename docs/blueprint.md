# **App Name**: 山宁 SANITEA - AI 灵感择茶

## Core Features:

- 状态感应 AI 问答器: 基于 Next.js 的多步骤互动式问答工具，通过六大维度（状态、偏好、场景、冷热、季节、忌口）捕捉用户当前的身心能量状态。
- 动态生成今日茶方: 基于 AI 逻辑处理用户输入，实时匹配最适合的山宁茶饮，生成包含推荐理由、契合度及口味剖面图的视觉结果卡片。
- 四季与地理环境检测: 系统工具会自动获取当前的季节属性（如春季、干燥秋季）结合用户选择的天气感知，作为 AI 选茶的首要环境权重因子。
- 草本成分可视化预览: 针对推荐茶品，动态展示核心草本成分（如桂花、枸杞）的精致线稿与现代阐释，辅助用户了解产品成分逻辑。
- 智能化二次备选引擎: 在主推荐之外，AI 会推荐 3-4 款契合度接近的备选方案，确保用户在多元化的山宁产品体系中获得灵感选择。
- 草本状态解读模块: 详细解析“为何这样推荐”的 AI 逻辑，将口味、状态、季节、场景四大维度通过可视化小部件展示给用户。
- 多终端响应式交互导航: 沉浸式、带有磨砂玻璃效果的品牌导航，支持全端无缝体验山宁品牌理念。包括非医疗性建议的安全提醒指引。

## Style Guidelines:

- 主色：深海蓝黑 (#0E1116)，传达静谧与深邃的东方夜色感。
- 点缀色：香槟金 (#D4B868)，用于 UI 边框、核心文字和草本植物线稿，提升轻奢感。
- 文字：米白 (#F5F0E6) 为主要正文色，避免高亮纯白造成的视觉疲劳；次要信息采用灰蓝 (#6B7280)。
- 推荐标题及品牌名称：使用 'Literata' (Serif) 营造传统与诗性的古典文学韵味。
- 正文及界面 UI：使用 'Inter' (Sans-serif) 保持现代客观感与在高亮环境下的极佳易读性。
- 使用极细线条感 (Light Weight) 的金色金色植物线稿（桂花、茶梗）及水波纹等东方抽象图标。
- 采用典型的单栏（移动端）与分栏（桌面端）相结合，保持大量的负空间（White Space）来实现呼吸感与高级感。
- 交互采用柔和的微动效，包含：背景云雾缓缓流体变换、卡片生成的淡淡金色呼吸闪烁，以及切换时的柔顺淡入淡出效果。
